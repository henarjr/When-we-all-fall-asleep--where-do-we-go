# When We Fall Asleep, Where Do We Go? 🌙

**When We Fall Asleep, Where Do We Go?** is a 2D adventure game built with Unity, taking you through three strange dream worlds filled with unexpected encounters, broken machines, and mysteries waiting to unfold.

Explore unfamiliar places, meet unusual characters, collect coins, and help restore order to worlds that seem to have gone wrong. But remember: not every problem can be solved by fighting.

And maybe, not everything is as it seems. 👁️

## 🎮 Gameplay

Travel through different dream worlds, interact with their inhabitants, repair malfunctioning machines, and find your way through each level.

From out-of-control robots to chaotic laboratories and runaway vending machines, every dream brings something new to discover.

## 🕹️ How to Play

| Input | Action |
|---|---|
| `W` / `A` / `S` / `D` | Move |
| `Space` | Shoot |
| `E` | Interact |

## ✨ Features

- 2D adventure and exploration gameplay.
- Three unique dream worlds.
- Interactable characters and objects.
- Shooting mechanics and environmental challenges.
- Collectible coins and healing items.
- Robot repair and problem-solving elements.

## 🛠️ My Additions & Improvements

While following the Unity Learn course, I expanded the project with my own additions to create a more complete and varied adventure.

- **Opening Cutscene:** Created an introductory cutscene to set the mood before the adventure begins.
- **Three Unique Levels:** Built three levels with different environments, giving each dream world its own identity.
- **Different Characters:** Added different characters across the levels to make each world feel distinct.

These additions helped me explore level design, scene management, and creating more engaging game experiences through environmental and character variety.
